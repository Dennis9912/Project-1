# 🏗️ 2-Tier AWS Static Web Application (Terraform)

This project provisions a fully automated, highly available **2-tier architecture** on AWS to host a **static web application**, leveraging **Terraform modules** for infrastructure as code (IaC). 
The stack includes core AWS services such as **VPC**, **EC2**, **ALB**, and **Route 53** with GitHub as the source control backbone.
